# Переход после верхней анимации

После фактической отрисовки последнего кадра и прокрутки пользователем вниз верхняя сцена за 640 мс переходит к следующему разделу. Остаток закреплённого участка больше не нужно докручивать вручную. Следующий раздел располагается с учётом отступа под навигацией.

Переход срабатывает один раз за прохождение сцены. Дальше сохраняется обычная прокрутка. При возвращении в начало анимации переход снова доступен. Прокрутка вверх, Escape, навигационные клавиши или нажатие мышью отменяют переход. Переходы по якорям и программная прокрутка сами по себе его не запускают. При reduced motion автоматического перемещения нет.

Код: `src/lib/hero-exit.js`, подключение только в `src/sections/ScrollFilm.jsx`. Остальные анимации не используют этот механизм.

Проверка: `npm.cmd run test:hero-exit`. Настоящие события колеса, PageDown и touch-свайпа, завершение на последнем кадре, точка прибытия, обычный скролл после перехода, отмена движением вверх и reduced motion. Скриншоты и результаты: `artifacts/qa/hero-exit`. Производственная сборка проходит.
