# Каталог из папок

Добавлен сканер `scripts/catalog/read-catalog.mjs` и виртуальный модуль Vite. Категории и работы читаются из `public/catalog` при сборке; dev-сервер отслеживает изменения и автоматически перечитывает каталог. Публикация остаётся статической и требует пересборки после обновления фотографий.

Подготовлены дофаминовый декор (10 работ, пять ваз и пять конфетниц), пустые интерьерные картины и артбокс. Для сирени и кофе созданы пустые папки без предположительно назначенных фотографий. Названия берутся из файлов/папок. Несколько снимков внутри папки показываются ракурсами одной работы. Возможны новые разделы без изменения React-компонентов.

Старые идентификаторы подборок переведены в новые через таблицу совместимости. Новые работы без заданного цвета поддерживаются в карточке, просмотре, подборке и WhatsApp. Фотоархив сохраняет 73 снимка без повторного добавления ракурсов в общий список.

AOS обновлён до 3.0.0-beta.6 с `once: false` и `mirror: true`: библиотека поддерживает выход и повторный вход анимации при прокрутке в обе стороны. Настройки подтверждены документацией автора: https://github.com/michalsnik/aos/blob/next/README.md. Reduced motion оставляет контент видимым.

Проверки:

- `npm.cmd run build`: производственная сборка.
- `node tests/catalog.mjs`: имя из файла, несколько ракурсов, одинаковые файлы внутри работы, пустые и новые категории.
- `node tests/e2e/catalog-live.mjs`: создание и переименование папки/фото в работающем dev, новая карточка в подборке и WhatsApp, просмотр, AOS при выходе и входе сверху/снизу. Временная категория переносится в `artifacts/qa`, на сайте её не остаётся.
- `npm.cmd run test:e2e`: desktop 1440, tablet 768, phone 390, compact 360, reduced motion; языки, сохранение выбора, копирование, фотоархив, мобильные свайпы, закрепление вступления до последнего кадра.

Результаты и скриншоты: `artifacts/qa/catalog-release`. Пользовательская инструкция: `docs/catalog-guide.md`.
