# Четыре новых видео: ритм страницы

Сохранены прежнее вступление и интерьерная сцена перед подборкой. Четыре новых ролика распределены в две композиции, движущиеся при обычном скролле, без дополнительных закреплённых экранов.

## Путь по странице

Вступление → заявление автора → **цвет** → каталог → **сервировка** → мастерская → интерьерная сцена → подборка → контакты.

**Цвет**: голубая гортензия и жёлтые лимоны. Два вертикальных кадра с разными отступами и небольшой разницей перемещения, заголовок «Цвет меняет настроение». Место до каталога знакомит с контрастом коллекции.

**Сервировка**: ягодный mix и белая конфетница. Большая сцена стола и меньший кадр с деталями, заголовок «Для встреч. И просто для себя». Место после каталога показывает работы в повседневной жизни и ведёт к мастерской.

На телефоне кадры идут последовательно со смещением вправо/влево. Видео остаётся вертикальным и показывается без обрезания внутри рамки. Все подписи и тексты переведены на RU / EN / AZ.

## Движение и загрузка

Общий `src/hooks/useFrameSequence.js` поддерживает два режима: прежнее закреплённое воспроизведение и движение по всей видимой жизни кадра в потоке страницы. Прокрутка назад возвращает видео назад. Framer Motion сглаживает прогресс, Canvas смешивает соседние кадры. Новые ролики не стоят замороженными на протяжении всего входа/выхода из экрана.

Каждый ролик имеет отдельные desktop/mobile WebP-последовательности с интерполяцией до 30 fps: 238 кадров для двух восьмисекундных роликов, 298 для двух десятисекундных. Кадры начинают загружаться рядом со сценой. Декодированный кэш ограничен 24 кадрами на компьютере / 12 на телефоне. При уходе далеко от новых сцен кэш освобождается; повторный вход использует HTTP-кэш браузера. При reduced motion видны статичные постеры без загрузки последовательностей.

Оригиналы: `assets/originals/video`. Последовательности: `public/media/stories`. Данные и переводы: `src/data/motion-stories.js`. Повторная подготовка: `node scripts/media/build-stories.mjs <путь к ffmpeg.exe>`.

## Сравнение

- Первая композиция: http://localhost:5173/#story-color
- Вторая: http://localhost:5173/#story-ritual
- Без четырёх новых видео: http://localhost:5173/?stories=off
- Постоянное отключение: `motionStories: false` в `src/data/experiments.js`. Прежние сцены при этом сохраняются.

## Проверки

`npm.cmd run test:stories`: четыре ролика вперёд/назад, повторный вход после освобождения кэша, лимит декодированных кадров, отложенная загрузка, отсутствие HTTP/JS ошибок, RU/EN/AZ и отключение новых сцен. Размеры 1440×1000, 768×1024, 390×844, 360×640 и reduced motion. Результаты и скриншоты: `artifacts/qa/motion-stories`.

Регрессии: `npm.cmd run test:interior` и `npm.cmd run test:e2e` проверяют прежние сцены и функции каталога. Сборка: `npm.cmd run build`.
