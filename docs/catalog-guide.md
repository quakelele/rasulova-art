# Как пополнять каталог

Все работы сайта находятся в `public/catalog`. Код менять не нужно.

## Разделы

- `01-Дофаминовый декор/Вазы` — вазы.
- `01-Дофаминовый декор/Конфетницы` — конфетницы.
- `02-Интерьерные картины` — картины.
- `03-Артбокс` — артбоксы.

Чтобы создать новый раздел, добавьте рядом папку, например `04-Скульптуры`. Число задаёт порядок; в заголовке оно не показывается. Пустой раздел отображает заглушку.

## Одна фотография на работу

Положите в раздел файл с названием работы:

```text
public/catalog/02-Интерьерные картины/Тихое утро.jpg
```

Карточка получит название **Тихое утро**. Переименуйте файл, чтобы изменить название. Поддерживаются JPG, JPEG, PNG, WebP, AVIF и GIF. HEIC сначала экспортируйте в JPG.

## Несколько фотографий одной работы

Создайте папку с названием работы и положите внутрь её ракурсы:

```text
public/catalog/02-Интерьерные картины/Морской свет/01.jpg
public/catalog/02-Интерьерные картины/Морской свет/02.jpg
```

Это одна карточка **Морской свет**, внутри которой два снимка. Первый файл по порядку станет обложкой. Точные копии внутри работы исключаются. Альтернатива без подпапки: `Морской свет__01.jpg` и `Морской свет__02.jpg`.

Для декора используйте, например:

```text
public/catalog/01-Дофаминовый декор/Вазы/Ваза «Новая работа»/01.jpg
public/catalog/01-Дофаминовый декор/Конфетницы/Конфетница «Новая работа»/01.jpg
public/catalog/03-Артбокс/Артбокс «Весна»/01.jpg
```

Папки **Ваза «сирень»** и **Конфетница «кофе»** уже подготовлены. Положите в них фотографии, и работы появятся. Пока они пустые, карточек нет.

## Когда появятся изменения

При запущенном `npm.cmd run dev` сайт сам перечитает каталог и обновит страницу после добавления, переименования или удаления файлов. Выбранные работы и язык сохраняются в браузере.

Для опубликованного сайта нужно заново выполнить `npm.cmd run build` и загрузить новую сборку `dist` на хостинг. Добавление файлов только на компьютер не обновляет уже опубликованную статическую сборку.

## Дополнительные настройки

Названия работ остаются такими, как вы их написали. Стандартные разделы и интерфейс переведены на RU / EN / AZ. Для перевода нового раздела можно добавить внутрь `section.json`:

```json
{
  "title": {"ru": "Скульптуры", "en": "Sculptures", "az": "Heykəllər"},
  "description": {"ru": "Авторские скульптуры", "en": "Sculptures by the artist", "az": "Müəllif heykəlləri"}
}
```

Это необязательно: без файла заголовок берётся из папки. Существующие `_item.json` хранят служебные идентификаторы и связи с прежними подборками. Для обычного добавления работ они не нужны. Сохраняйте их у существующих работ.

Оригиналы остаются в `assets/originals`. Папка `public/media` обслуживает стартовую анимацию и фотоархив; новые работы добавляйте именно в `public/catalog`.
