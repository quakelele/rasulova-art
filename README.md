# RASULOVA ART

Галерея авторских объектов на React + Vite. Интерфейс на русском, английском и азербайджанском. Названия работ сохранены без изменений.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Сайт: http://localhost:5173. Сборка: `npm.cmd run build`. Просмотр сборки: `npm.cmd run preview` (порт 4173).

## Возможности

Тест второй анимации после мастерской: [описание и откат](docs/reports/interior-scroll-experiment.md). Для сравнения откройте `/?interior=off`; постоянный переключатель находится в `src/data/experiments.js`.

Четыре новых ролика объединены в две композиции по скроллу: «Цвет» перед каталогом и «Сервировка» после него. [Расположение, проверка и отключение](docs/reports/four-motion-stories.md). Для сравнения: `/?stories=off`.

- Стартовая анимация на 193 WebP-кадрах с Framer Motion. Обратный таймлайн приближает камеру к вазе. Первый экран остаётся закреплённым до последнего кадра; во время сцены сменяются три текста.
- AOS 3 для повторного появления блоков при прокрутке вверх и вниз. Reduced motion поддерживается.
- Swiper с инерцией, touch-свайпами, стрелками и клавиатурой. Фотографии видны целиком.
- Каталог из папок: дофаминовый декор, интерьерные картины, артбоксы и любые новые разделы. Сейчас 10 работ, фотоархив из 73 снимков и пять историй мастерской.
- Отдельные действия «Рассмотреть» и «В подборку», полноразмерный просмотр с миниатюрами, сохранение выбора в браузере.
- RU / EN / AZ с сохранением языка и переведённым текстом обращения.
- Контакты: WhatsApp/телефон +994 55 444 89 54 и Instagram https://www.instagram.com/rasulova_art/.

WhatsApp открывается с готовым текстом. Пользователь подтверждает отправку в чате. Фотографии автоматически не прикрепляются.

## Структура

```text
src/app/                    сборка страницы
src/sections/               разделы лендинга
src/components/gallery/     карточка работы, Swiper, просмотр
src/components/navigation/  переключатель языка
src/i18n/                   переводы и состояние языка
src/data/                   каталог и контакты
src/lib/                    сообщения автору
src/hooks/                  AOS
src/styles/                 стили по назначению
assets/originals/           оригинальные фото и видео
assets/archive/             сохранённые старые производные файлы
public/media/               только медиа, используемые сайтом
scripts/media/              подготовка изображений и кадров
scripts/archive/            исторические одноразовые инструменты
tests/e2e/                  актуальная проверка
tests/archive/              предыдущие проверки
artifacts/qa/               скриншоты и результаты, не отслеживаются Git
docs/reports/               актуальные отчёты
docs/media/                 аудит и история переноса файлов
docs/iterations/            прежние брифы и решения
```

Работы добавляются в `public/catalog`: название файла или папки становится названием карточки. Полная инструкция с примерами: [docs/catalog-guide.md](docs/catalog-guide.md). Локальный сервер обновляется автоматически; опубликованный сайт требует новой сборки и загрузки на хостинг.

Сканер: `scripts/catalog/read-catalog.mjs`. Vite подключает каталог через виртуальный модуль. Контакты: `src/data/contact-config.js`. Переводы: `src/i18n/messages.js`.

## Проверка

При работающем `npm.cmd run preview`:

```powershell
npm.cmd run test:e2e
```

Нужен установленный Chrome. Проверяются desktop, планшет, два мобильных размера и reduced motion. Актуальные результаты: `artifacts/qa/catalog-release/results.json`. Сканер проверяется командой `node tests/catalog.mjs`. При работающих dev и preview: `node tests/e2e/catalog-live.mjs` проверяет добавление и переименование работы без перезапуска, а также AOS в обе стороны.

Отчёт об изменениях: `docs/reports/languages-and-gallery.md`.

## Подготовка медиа

`SCROLLCRAFT_FFMPEG` должен указывать на полный FFmpeg. Оптимизация изображений: `node scripts/media/optimize-images.mjs`. Раскадровка: `scripts/media/build-sequence.ps1 -FfmpegPath <путь>`. Каталог определяет используемые оригиналы; исходные загрузки сохранены. Архивные скрипты и проверки описывают предыдущие версии и не являются текущими точками запуска.
